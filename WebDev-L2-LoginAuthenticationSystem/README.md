# Login Authentication System

A front-end authentication demo made with HTML, CSS and vanilla JavaScript.

## Features
- Registration with username, email and password
- Password rule: minimum 8 characters and at least one number
- Duplicate username/email check
- Login with generic credential error
- Protected dashboard using sessionStorage
- Logout
- SHA-256 password hashing before storing demo credentials
- Basic form validation

## Important note
This is a learning/demo project. Browser localStorage/sessionStorage authentication is not suitable for a real production login system. A production app should use a server, secure sessions/tokens, HTTPS and a proper password-hashing library.

## Run
Open `register.html` first to create a demo account, then log in through `index.html`.
